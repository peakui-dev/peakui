## Requirements

- [React 19](https://react.dev/) or later
- [Tailwind CSS v4](https://tailwindcss.com/docs/installation)

## Install

Install the two PeakUI packages together with their peer dependencies:

```npm
npm install @peakui/react @peakui/styles react-aria-components @react-aria/utils
```

`react-aria-components` and `@react-aria/utils` are peer dependencies of `@peakui/react`. Tailwind CSS is a peer dependency of `@peakui/styles`; if your project does not have it yet, follow the [Tailwind CSS installation guide](https://tailwindcss.com/docs/installation) for your framework first.

## Import Styles

Add both imports to your main CSS file, for example `app/globals.css`:

```css title="globals.css"
@import "tailwindcss";
@import "@peakui/styles/css";
```

<Callout type="warn">
  The order matters. `@peakui/styles` extends Tailwind and does not import it. If Tailwind comes second, or is missing, the component styles are silently absent: there is no build error.
</Callout>

## Use Components

Import components from the package root:

```tsx
import {Button, Input, Label, TextField} from "@peakui/react";

export function SignUp() {
  return (
    <form className="flex w-64 flex-col gap-3">
      <TextField isRequired name="email" type="email">
        <Label>Email</Label>
        <Input placeholder="jane@example.com" />
      </TextField>
      <Button type="submit">Sign up</Button>
    </form>
  );
}
```

There is no provider to add. The theme lives in CSS.

## Server Components

Every PeakUI component is a client component, marked with `"use client"`. You can render one from a server component, but you cannot pass it a function from there. Props such as `onPress`, a `className` function or children written as a render function need a file that itself starts with `"use client"`.

## Tailwind class detection

Tailwind finds class names by scanning your source files as text. Two consequences:

- Write class names in full. `className={isActive ? "bg-accent" : "bg-default"}` works; a name assembled by interpolation, such as `` `bg-${role}` ``, never reaches the CSS.
- Files outside your app's own sources are not scanned. If utility classes live in a shared package, point Tailwind at it with [`@source`](https://tailwindcss.com/docs/detecting-classes-in-source-files).
