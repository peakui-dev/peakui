---
title: Agent Skills
description: Install the PeakUI skill so your AI coding agent writes correct PeakUI code.
---

The `peakui-react` skill teaches a coding agent how PeakUI components are composed and styled. For each component it uses, the agent reads the documentation page from this site.

## Install

```bash
npx skills add peakui-dev/peakui
```

The skill is copied to `.agents/skills/peakui-react/` and linked from `.claude/skills/peakui-react/`, the two folders coding agents read skills from.

## Point Your Agent at It

Agents do not always load an installed skill on their own. Paste this block into `AGENTS.md` and `CLAUDE.md` at the root of your project:

```md
<!-- peakui:start -->
This project uses PeakUI (`@peakui/react`, `@peakui/styles`).
Before writing or changing UI code, load the `peakui-react` skill and follow it.
Without skills: read https://peakui.dev/llms.txt first.
<!-- peakui:end -->
```

## Update

```bash
npx skills update
```

## What the Scripts Access

The skill ships two scripts that the agent runs with Node.js 18 or later.

| Script | Reads | Network |
|--------|-------|---------|
| `scripts/docs.mjs` | The documentation index and the pages the agent asks for | `GET` requests to this site, nothing else |
| `scripts/doctor.mjs` | Your project's `package.json`, installed package versions and CSS imports | None |

Neither script writes a file or sends anything about your project.

## Mirrors and Previews

Set `PEAKUI_DOCS_URL` to read the documentation from another origin:

```bash
PEAKUI_DOCS_URL=https://docs.internal.example node .agents/skills/peakui-react/scripts/docs.mjs list
```
