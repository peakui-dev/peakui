## Usage

```tsx
import {ErrorMessage} from "@peakui/react";
```

<ComponentPreview name="error-message-basic" />

`ErrorMessage` presents the `errorMessage` slot of a parent such as `TagGroup`; the parent decides when the message shows. For a form field's validation errors, use [FieldError](/docs/react/components/field-error), which renders them while the field is invalid.

<Callout type="warn">
  Outside a parent that publishes the `errorMessage` slot, `ErrorMessage` still renders its `<span>`, but nothing links it to a control. Inside such a parent, the message is announced with it through `aria-describedby` while it is mounted.
</Callout>

## API Reference

### ErrorMessage

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | The error message |
| `className` | `string` | - | Additional classes |
| `elementType` | `string` | `'span'` | The element to render |
| `render` | `DOMRenderFunction<any, any>` | - | Replaces the rendered element with your own. React Aria types it loosely because `elementType` can change the element |

The `slot` defaults to `errorMessage`; it is what links the message to the parent, so leave it as it is.
