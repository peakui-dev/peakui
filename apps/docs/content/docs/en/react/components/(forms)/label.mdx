## Usage

```tsx

```

## Examples

### In a TextField

Inside a `TextField` the label is linked to the input automatically, and it follows the field's required, invalid and disabled states. You do not pass the state props.

## Customization

### Tailwind CSS

```tsx
<Label className="text-xs tracking-wide uppercase">Email</Label>
```

### Global CSS

```css
@layer components {
  .label {
    @apply font-semibold;
  }
}
```

## Styling Reference

### CSS Classes

The Label component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/label.css)):

- `.label` - Base label styles
- `.label--required` - Adds the required indicator
- `.label--invalid` - Invalid state color
- `.label--disabled` - Disabled state

### Slots

- `[data-slot="label"]`

### Interactive States

Inside a field, the label is styled from the field root's attributes:

- **Required**: `[data-required]` on the field
- **Invalid**: `[data-invalid]` on the field
- **Disabled**: `[data-disabled]` on the field

## API Reference

### Label

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isRequired` | `boolean` | `false` | Shows the required indicator. Not needed inside a `TextField` |
| `isInvalid` | `boolean` | `false` | Applies the invalid style. Not needed inside a `TextField` |
| `isDisabled` | `boolean` | `false` | Applies the disabled style. Not needed inside a `TextField` |
| `htmlFor` | `string` | - | The id of the control the label describes. Set automatically inside a `TextField` |
| `elementType` | `string` | `'label'` | The element to render |
| `children` | `React.ReactNode` | - | The label text |
| `className` | `string` | - | Additional classes |

Every other attribute of a `<label>` is accepted.
