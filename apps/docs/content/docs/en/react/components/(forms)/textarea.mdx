## Styling Reference

### CSS Classes

| Class | Description
| :- | :-
| `.textarea` | The textarea element
| `.textarea--primary`, `.textarea--secondary` | Variant modifiers
| `.textarea--full-width` | Full-width modifier

### Slots

| Slot | Description
| :- | :-
| `[data-slot="textarea"]` | The textarea element

### Interactive States

The component supports both CSS pseudo-classes and data attributes:

| State | Attribute
| :- | :-
| Focused | `:focus-visible` / `[data-focus-visible="true"]` (from the owning field)
| Hovered | `:hover` (from the owning field)
| Disabled | `:disabled`
| Invalid | `[data-invalid="true"]` (from the owning field)

## API Reference

### TextArea.Root

| Prop | Type | Default | Description
| :- | :- | :- | :-
| `variant` | `"primary" \| "secondary"` | `"primary"` | Visual variant; inherited from the owning `TextField` when unset
| `fullWidth` | `boolean` | `false` | Stretches to the container width
| `value` | `string` | - | Controlled value
| `defaultValue` | `string` | - | Uncontrolled initial value
| `isDisabled` | `boolean` | - | Disables the textarea
| `isReadOnly` | `boolean` | - | Makes the textarea read-only
| `isRequired` | `boolean` | - | Marks the textarea required
| `rows` | `number` | - | Visible row count
| `onChange` | `(event) => void` | - | Native change handler; read the value from `event.target.value`
| `...rest` | | | Every React Aria `TextArea` attribute is accepted
