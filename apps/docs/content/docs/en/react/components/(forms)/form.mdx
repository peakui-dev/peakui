## Usage

```tsx
import {Form} from "@peakui/react";
```

<ComponentPreview name="form-basic" />

## Examples

Fields inside a form validate on submit; blocking an invalid submission is the browser's native constraint validation.

### Validation Behavior

```tsx
<Form validationBehavior="aria" aria-label="Profile">
  {/* fields validate on blur and show errors without blocking submit */}
</Form>
```

## Customization

### Tailwind CSS

```tsx
<Form aria-label="Profile" className="flex flex-col gap-4">
```

## API Reference

### Form.Root

| Prop | Type | Default | Description
| :- | :- | :- | :-
| `validationErrors` | `Record<string, string \| string[]>` | - | Server-side errors keyed by field name
| `validationBehavior` | `"native" \| "aria"` | `"native"` | With `native`, the browser blocks invalid submits (`noValidate` stays off); with `aria`, validation is announced without blocking
| `onSubmit` | `(event) => void` | - | Native submit handler; read values from the form elements
| `...rest` | | | Every React Aria `Form` attribute is accepted
