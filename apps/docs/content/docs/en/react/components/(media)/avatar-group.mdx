## Usage

```tsx
import {Avatar, AvatarGroup} from "@peakui/react";
```

<ComponentPreview name="avatar-group-basic" />

### Anatomy

```tsx
import {Avatar, AvatarGroup} from "@peakui/react";

export default () => (
  <AvatarGroup>
    <Avatar>
      <Avatar.Image />
      <Avatar.Fallback />
    </Avatar>
    <AvatarGroup.Count /> {/* Optional */}
  </AvatarGroup>
);
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The AvatarGroup component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/avatar-group.css)):

#### Base & Element Classes [!toc]

- `.avatar-group` - Base container
- `.avatar-group__count` - Overflow count avatar

#### Layout Classes [!toc]

- `.avatar-group--grid` - Wrapping grid, no overlap

#### Overlap Classes [!toc]

- `.avatar-group--clip` - Crescent mask with a transparent seam, the default
- `.avatar-group--ring` - Solid outline in the background color

### Slots

- `[data-slot="avatar-group"]`
- `[data-slot="avatar-group-count"]`

### CSS Variables

| Variable | Purpose |
|----------|---------|
| `--avatar-group-overlap` | How far each avatar sits over its neighbour (`0.5rem`) |
| `--avatar-group-seam` | Width of the seam or ring between avatars (`2px`) |

## API Reference

### AvatarGroup

Only direct `Avatar` children receive `size`, `color`, `variant` and the `max` cut: an `Avatar` inside a wrapper component is left alone. The group has no default `role`; pass `role="group"` with `aria-label` when the stack is meaningful.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size given to children that omit `size` |
| `color` | `'default' \| 'accent' \| 'success' \| 'warning' \| 'danger'` | - | Color given to children that omit `color` |
| `variant` | `'default' \| 'soft'` | - | Variant given to children that omit `variant` |
| `max` | `number` | - | Most avatars to render; omit to render all |
| `overlap` | `'clip' \| 'ring'` | `'clip'` | Stacked overlap style; ignored when `isGrid` |
| `isGrid` | `boolean` | `false` | Wraps the avatars in a grid without overlap |
| `children` | `ReactNode` | - | `Avatar` elements and an optional `AvatarGroup.Count` |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<E, undefined>` | - | Replaces the rendered element; `E` defaults to `'div'` |
| `...rest` | | | Every `<div>` attribute is accepted |

### AvatarGroup.Count

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | Count content, such as `+3` |
| `size` | `'sm' \| 'md' \| 'lg'` | group's | Overrides the group's size |
| `color` | `'default' \| 'accent' \| 'success' \| 'warning' \| 'danger'` | group's | Overrides the group's color |
| `variant` | `'default' \| 'soft'` | group's | Overrides the group's variant |
| `className` | `string` | - | Additional classes |
| `...rest` | | | Every `<span>` attribute is accepted |
