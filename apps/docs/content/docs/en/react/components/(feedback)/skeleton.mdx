## Customization

### Tailwind CSS

Size and shape come from the consumer — the block itself ships with no dimensions.

```tsx
<Skeleton className="h-32 w-full rounded-xl" />
```

### Global CSS

Set `--skeleton-animation` on `:root` to change the default animation type for every Skeleton at once; the `animationType` prop still wins per component.

```css
@layer components {
  .skeleton {
    @apply bg-surface-secondary/70;
  }

  .skeleton--pulse {
    @apply animate-pulse;
  }
}

:root {
  /* Possible values: shimmer, pulse, none */
  --skeleton-animation: pulse;
}
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The Skeleton component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/skeleton.css)):

#### Base Class [!toc]

- `.skeleton` - Base skeleton styles with background and rounded corners

#### Animation Variant Classes [!toc]

- `.skeleton--shimmer` - Shimmer animation with a moving gradient (default)
- `.skeleton--pulse` - Pulse animation
- `.skeleton--none` - Static placeholder without animation

### Slots

- `[data-slot="skeleton"]` - The root element

## API Reference

### Skeleton

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `animationType` | `'shimmer' \| 'pulse' \| 'none'` | `'shimmer'` or `--skeleton-animation` | Animation type; the CSS variable sets the app-wide default |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<'div', undefined>` | - | Replaces the rendered `<div>` with your own element |

Every other attribute of a `<div>` is accepted.
