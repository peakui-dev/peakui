## Usage

```tsx
import {RangeCalendar} from "@peakui/react";
```

<ComponentPreview name="range-calendar-basic" />

### Anatomy

```tsx
import {RangeCalendar} from "@peakui/react";

export default () => (
  <RangeCalendar>
    <RangeCalendar.Header>
      <RangeCalendar.Heading />
      <RangeCalendar.NavButton slot="previous" />
      <RangeCalendar.NavButton slot="next" />
    </RangeCalendar.Header>
    <RangeCalendar.Grid>
      <RangeCalendar.GridHeader>
        {(day) => <RangeCalendar.HeaderCell>{day}</RangeCalendar.HeaderCell>}
      </RangeCalendar.GridHeader>
      <RangeCalendar.GridBody>
        {(date) => (
          <RangeCalendar.Cell date={date}>
            <RangeCalendar.CellIndicator />
          </RangeCalendar.Cell>
        )}
      </RangeCalendar.GridBody>
    </RangeCalendar.Grid>
    <RangeCalendar.YearPickerGrid>
      <RangeCalendar.YearPickerGridBody>
        {({year}) => <RangeCalendar.YearPickerCell year={year} />}
      </RangeCalendar.YearPickerGridBody>
    </RangeCalendar.YearPickerGrid>
  </RangeCalendar>
);
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The RangeCalendar component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/range-calendar.css)):

#### Base Classes [!toc]

- `.range-calendar` - Root container, 252px wide
- `.range-calendar__header` - Heading and navigation row
- `.range-calendar__heading` - Month and year text
- `.range-calendar__nav-button` - Previous and next buttons
- `.range-calendar__nav-button-icon` - Default chevron in a nav button
- `.range-calendar__grid` - Month grid
- `.range-calendar__grid-header` - Weekday row
- `.range-calendar__header-cell` - Weekday name
- `.range-calendar__grid-body` - Date rows
- `.range-calendar__grid-row` - Hook for custom row styling
- `.range-calendar__cell` - Date cell; carries the range track
- `.range-calendar__cell-button` - Round day inside a cell; carries the range caps
- `.range-calendar__cell-indicator` - Dot at the bottom of a cell

#### Modifier Classes [!toc]

- `.range-calendar--week-view` - Set when `visibleDuration` is in weeks
- `.range-calendar--day-view` - Set when `visibleDuration` is in days

#### Year Picker Classes [!toc]

- `.calendar-year-picker__trigger` - Button that replaces the heading
- `.calendar-year-picker__trigger-heading` - Month and year text
- `.calendar-year-picker__trigger-indicator` - Chevron, turned while open
- `.calendar-year-picker__year-grid` - Three-column grid laid over the date grid
- `.calendar-year-picker__year-cell` - Year button

### Interactive States

The component supports both CSS pseudo-classes and data attributes:

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[data-disabled="true"]`
- **Selected**: `[data-selected="true"]` on every cell in the range
- **Range start**: `[data-selection-start="true"]` on a cell
- **Range end**: `[data-selection-end="true"]` on a cell
- **Today**: `[data-today="true"]` on a cell
- **Outside month**: `[data-outside-month="true"]` on a cell
- **Unavailable**: `[data-unavailable="true"]` on a cell
- **Open**: `[data-open="true"]` on the year picker trigger and grid

## API Reference

### RangeCalendar

| Prop                        | Type                                                          | Default       | Description                                                      |
| --------------------------- | ------------------------------------------------------------- | ------------- | ---------------------------------------------------------------- |
| `value`                     | `RangeValue<DateValue> \| null`                               | -             | The selected range (controlled)                                  |
| `defaultValue`              | `RangeValue<DateValue> \| null`                               | -             | The initial selected range (uncontrolled)                        |
| `onChange`                  | `(value: RangeValue<MappedDateValue<DateValue>>) => void`     | -             | Called when a range is completed                                 |
| `minValue`                  | `DateValue`                                                   | 1 Jan 1900    | The earliest selectable date, in the locale's calendar           |
| `maxValue`                  | `DateValue`                                                   | 31 Dec 2099   | The latest selectable date, in the locale's calendar             |
| `isDateUnavailable`         | `(date: DateValue, anchorDate: CalendarDate \| null) => boolean` | -          | Marks a date as unavailable; `anchorDate` is the first chosen date |
| `allowsNonContiguousRanges` | `boolean`                                                     | `false`       | With `isDateUnavailable`, lets a range contain unavailable dates |
| `isDisabled`                | `boolean`                                                     | `false`       | Disables the whole calendar                                      |
| `isReadOnly`                | `boolean`                                                     | `false`       | Allows focus and navigation but not selection                    |
| `isInvalid`                 | `boolean`                                                     | -             | Marks the selection as invalid                                   |
| `visibleDuration`           | `DateDuration`                                                | `{months: 1}` | The span shown at once: `months`, `weeks` or `days`              |
| `firstDayOfWeek`            | `"sun" \| "mon" \| "tue" \| "wed" \| "thu" \| "fri" \| "sat"` | locale        | The first day of the week                                        |
| `focusedValue`              | `DateValue`                                                   | -             | The focused date (controlled)                                    |
| `defaultFocusedValue`       | `DateValue`                                                   | -             | The initially focused date                                       |
| `onFocusChange`             | `(date: CalendarDate) => void`                                | -             | Called when the focused date changes                             |
| `isYearPickerOpen`          | `boolean`                                                     | -             | Whether the year picker is open (controlled)                     |
| `defaultYearPickerOpen`     | `boolean`                                                     | `false`       | Whether the year picker starts open                              |
| `onYearPickerOpenChange`    | `(isYearPickerOpen: boolean) => void`                         | -             | Called when the year picker opens or closes                      |
| `className`                 | `string \| ((values: RangeCalendarRenderProps) => string)`    | -             | Additional classes, or a function of the render props            |
| `children`                  | `ReactNode \| ((values: RangeCalendarRenderProps) => ReactNode)` | -          | The parts, or a function of the render props                     |
| `...rest`                   |                                                               |               | Every React Aria `RangeCalendar` prop, including `aria-label`    |

### Render Props

`RangeCalendar` and `RangeCalendar.Cell` pass the React Aria render props to `children` and `className` functions:

| Part                 | Values                                                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `RangeCalendar`      | `state`, `isDisabled`, `isInvalid`                                                                                                                           |
| `RangeCalendar.Cell` | `date`, `formattedDate`, `isSelected`, `isSelectionStart`, `isSelectionEnd`, `isFocused`, `isHovered`, `isPressed`, `isUnavailable`, `isOutsideMonth`, `isDisabled` |

The year picker parts share the render props of `Calendar`:

| Prop            | Type         | Description                                                             |
| --------------- | ------------ | ----------------------------------------------------------------------- |
| `isOpen`        | `boolean`    | Whether the year picker is open (trigger parts)                         |
| `monthYear`     | `string`     | The formatted month and year (trigger parts)                            |
| `toggle`        | `() => void` | Opens or closes the year picker (trigger parts)                         |
| `year`          | `number`     | The year (grid body and cell)                                           |
| `formattedYear` | `string`     | The year formatted for the locale and calendar (grid body and cell)     |
| `isSelected`    | `boolean`    | Whether the calendar is showing this year (grid body and cell)          |
| `isCurrentYear` | `boolean`    | Whether this is the present calendar year (grid body and cell)          |
| `selectYear`    | `() => void` | Shows this year and closes the picker (grid body and cell)              |
