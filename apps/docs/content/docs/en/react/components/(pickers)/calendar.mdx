## Usage

```tsx
import {Calendar} from "@peakui/react";
```

<ComponentPreview name="calendar-basic" />

### Anatomy

```tsx
import {Calendar} from "@peakui/react";

export default () => (
  <Calendar>
    <Calendar.Header>
      <Calendar.Heading />
      <Calendar.NavButton slot="previous" />
      <Calendar.NavButton slot="next" />
    </Calendar.Header>
    <Calendar.Grid>
      <Calendar.GridHeader>
        {(day) => <Calendar.HeaderCell>{day}</Calendar.HeaderCell>}
      </Calendar.GridHeader>
      <Calendar.GridBody>
        {(date) => (
          <Calendar.Cell date={date}>
            <Calendar.CellIndicator />
          </Calendar.Cell>
        )}
      </Calendar.GridBody>
    </Calendar.Grid>
    <Calendar.YearPickerGrid>
      <Calendar.YearPickerGridBody>
        {({year}) => <Calendar.YearPickerCell year={year} />}
      </Calendar.YearPickerGridBody>
    </Calendar.YearPickerGrid>
  </Calendar>
);
```

### Tailwind CSS

```tsx

  {/* ... */}

```

### Global CSS

```css
@layer components {
  .calendar {
    --calendar-width: calc(var(--spacing) * 80);
  }

  .calendar__cell[data-selected="true"] {
    --calendar-cell-bg-selected: var(--color-success);
    --calendar-cell-fg-selected: var(--color-success-foreground);
  }
}
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The Calendar component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/calendar.css)):

#### Base Classes [!toc]

- `.calendar` - Root container, 252px wide
- `.calendar__header` - Heading and navigation row
- `.calendar__heading` - Month and year text
- `.calendar__nav-button` - Previous and next buttons
- `.calendar__nav-button-icon` - Default chevron in a nav button
- `.calendar__grid` - Month grid
- `.calendar__grid-header` - Weekday row
- `.calendar__header-cell` - Weekday name
- `.calendar__grid-body` - Date rows
- `.calendar__grid-row` - Hook for custom row styling
- `.calendar__cell` - Date cell
- `.calendar__cell-indicator` - Dot at the bottom of a cell

#### Modifier Classes [!toc]

- `.calendar--week-view` - Set when `visibleDuration` is in weeks
- `.calendar--day-view` - Set when `visibleDuration` is in days

#### Year Picker Classes [!toc]

- `.calendar-year-picker__trigger` - Button that replaces the heading
- `.calendar-year-picker__trigger-heading` - Month and year text
- `.calendar-year-picker__trigger-indicator` - Chevron, turned while open
- `.calendar-year-picker__year-grid` - Three-column grid laid over the date grid
- `.calendar-year-picker__year-cell` - Year button

### CSS Variables

| Variable                          | Purpose                                 |
| --------------------------------- | --------------------------------------- |
| `--calendar-width`                | Width and maximum width of the calendar |
| `--calendar-cell-bg-hover`        | Hovered cell background                 |
| `--calendar-cell-bg-today`        | Today's cell background                 |
| `--calendar-cell-bg-today-hover`  | Hovered today's cell background         |

| `--calendar-cell-fg-selected`     | Selected cell text color                |

### Interactive States

The component supports both CSS pseudo-classes and data attributes:

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[data-disabled="true"]`
- **Selected**: `[data-selected="true"]` on a cell or a year cell
- **Today**: `[data-today="true"]` on a cell
- **Outside month**: `[data-outside-month="true"]` on a cell
- **Unavailable**: `[data-unavailable="true"]` on a cell
- **Open**: `[data-open="true"]` on the year picker trigger and grid

## API Reference

### Calendar

| Prop                     | Type                                          | Default    | Description                                              |
| ------------------------ | --------------------------------------------- | ---------- | -------------------------------------------------------- |
| `value`                  | `DateValue \| null`                           | -          | The selected date (controlled)                           |
| `defaultValue`           | `DateValue \| null`                           | -          | The initial selected date (uncontrolled)                 |
| `onChange`               | `(value: DateValue) => void`                  | -          | Called when the selection changes                        |
| `selectionMode`          | `"single" \| "multiple"`                      | `"single"` | Whether one date or several can be selected              |
| `minValue`               | `DateValue`                                   | 1 Jan 1900 | The earliest selectable date, in the locale's calendar   |
| `maxValue`               | `DateValue`                                   | 31 Dec 2099 | The latest selectable date, in the locale's calendar    |
| `isDateUnavailable`      | `(date: DateValue) => boolean`                | -          | Marks a date as unavailable                              |
| `isDisabled`             | `boolean`                                     | `false`    | Disables the whole calendar                              |
| `isReadOnly`             | `boolean`                                     | `false`    | Allows focus and navigation but not selection            |
| `isInvalid`              | `boolean`                                     | -          | Marks the selection as invalid                           |
| `visibleDuration`        | `DateDuration`                                | `{months: 1}` | The span shown at once: `months`, `weeks` or `days`   |
| `firstDayOfWeek`         | `"sun" \| "mon" \| "tue" \| "wed" \| "thu" \| "fri" \| "sat"` | locale | The first day of the week            |
| `focusedValue`           | `DateValue`                                   | -          | The focused date (controlled)                            |
| `defaultFocusedValue`    | `DateValue`                                   | -          | The initially focused date                               |
| `onFocusChange`          | `(date: CalendarDate) => void`                | -          | Called when the focused date changes                     |
| `isYearPickerOpen`       | `boolean`                                     | -          | Whether the year picker is open (controlled)             |
| `defaultYearPickerOpen`  | `boolean`                                     | `false`    | Whether the year picker starts open                      |
| `onYearPickerOpenChange` | `(isYearPickerOpen: boolean) => void`         | -          | Called when the year picker opens or closes              |
| `className`              | `string \| ((values: CalendarRenderProps) => string)` | -  | Additional classes, or a function of the render props    |
| `children`               | `ReactNode \| ((values: CalendarRenderProps) => ReactNode)` | - | The parts, or a function of the render props         |
| `...rest`                |                                               |            | Every React Aria `Calendar` prop, including `aria-label` |

### Render Props

`Calendar` and `Calendar.Cell` pass the React Aria render props to `children` and `className` functions:

| Part            | Values                                                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `Calendar`      | `state`, `isDisabled`, `isInvalid`                                                                                                 |
| `Calendar.Cell` | `date`, `formattedDate`, `isSelected`, `isFocused`, `isHovered`, `isPressed`, `isUnavailable`, `isOutsideMonth`, `isDisabled` |

`Calendar.YearPickerTrigger`, `Calendar.YearPickerTriggerHeading` and `Calendar.YearPickerTriggerIndicator` children receive:

| Prop        | Type         | Description                          |
| ----------- | ------------ | ------------------------------------ |
| `isOpen`    | `boolean`    | Whether the year picker is open      |
| `monthYear` | `string`     | The formatted month and year         |
| `toggle`    | `() => void` | Opens or closes the year picker      |

`Calendar.YearPickerGridBody` children and `Calendar.YearPickerCell` children receive:

| Prop            | Type         | Description                                        |
| --------------- | ------------ | -------------------------------------------------- |
| `year`          | `number`     | The year                                           |
| `formattedYear` | `string`     | The year formatted for the locale and calendar     |
| `isSelected`    | `boolean`    | Whether the calendar is showing this year          |
| `isCurrentYear` | `boolean`    | Whether this is the present calendar year          |
| `isOpen`        | `boolean`    | Whether the year picker is open                    |
| `selectYear`    | `() => void` | Shows this year and closes the picker              |
