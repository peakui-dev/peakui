
### Anatomy

```tsx
import {AlertDialog, Button} from "@peakui/react";

export default () => (
  <AlertDialog>
    <Button>Open alert dialog</Button>
    <AlertDialog.Backdrop>
      <AlertDialog.Container>
        <AlertDialog.Dialog>
          <AlertDialog.CloseTrigger /> {/* Optional: close button */}
          <AlertDialog.Header>
            <AlertDialog.Icon /> {/* Optional: status icon */}
            <AlertDialog.Heading />
          </AlertDialog.Header>
          <AlertDialog.Body />
          <AlertDialog.Footer />
        </AlertDialog.Dialog>
      </AlertDialog.Container>
    </AlertDialog.Backdrop>
  </AlertDialog>
);
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The AlertDialog component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/alert-dialog.css)):

#### Element Classes [!toc]

- `.alert-dialog__trigger` - Trigger element that opens the dialog
- `.alert-dialog__backdrop` - Overlay behind the dialog
- `.alert-dialog__container` - Positioning wrapper with placement support
- `.alert-dialog__dialog` - Dialog content container
- `.alert-dialog__header` - Header section for the icon and heading
- `.alert-dialog__heading` - Heading element
- `.alert-dialog__icon` - Status icon indicator
- `.alert-dialog__body` - Main content area
- `.alert-dialog__footer` - Footer section for actions
- `.alert-dialog__close-trigger` - Close button position

#### Backdrop Variant Classes [!toc]

- `.alert-dialog__backdrop--opaque` - Dimmed backdrop (default)
- `.alert-dialog__backdrop--blur` - Blurred backdrop
- `.alert-dialog__backdrop--transparent` - Transparent backdrop

#### Size Classes [!toc]

- `.alert-dialog__dialog--xs`
- `.alert-dialog__dialog--sm`
- `.alert-dialog__dialog--md`
- `.alert-dialog__dialog--lg`
- `.alert-dialog__dialog--cover` - Full height and width

#### Status Classes [!toc]

- `.alert-dialog__icon--default`
- `.alert-dialog__icon--accent`
- `.alert-dialog__icon--success`
- `.alert-dialog__icon--warning`
- `.alert-dialog__icon--danger`

### Slots

- `[data-slot="alert-dialog-trigger"]` - The `AlertDialog.Trigger` element
- `[data-slot="alert-dialog-backdrop"]` - The `AlertDialog.Backdrop` overlay
- `[data-slot="alert-dialog-container"]` - The `AlertDialog.Container` wrapper
- `[data-slot="alert-dialog-dialog"]` - The `AlertDialog.Dialog` element
- `[data-slot="alert-dialog-header"]` - The `AlertDialog.Header` element
- `[data-slot="alert-dialog-icon"]` - The `AlertDialog.Icon` element
- `[data-slot="alert-dialog-default-icon"]` - The icon rendered when `AlertDialog.Icon` has no children
- `[data-slot="alert-dialog-heading"]` - The `AlertDialog.Heading` element
- `[data-slot="alert-dialog-body"]` - The `AlertDialog.Body` element
- `[data-slot="alert-dialog-footer"]` - The `AlertDialog.Footer` element
- `[data-slot="alert-dialog-close-trigger"]` - The `AlertDialog.CloseTrigger` element

### Interactive States

The overlay parts carry React Aria animation states:

- **Entering**: `[data-entering="true"]`
- **Exiting**: `[data-exiting="true"]`
- **Placement**: `[data-placement="auto | top | center | bottom"]` on container and dialog

The trigger supports both pseudo-classes and data attributes:

- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[aria-disabled="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`

## API Reference

### AlertDialog

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | The trigger element followed by the overlay |
| `state` | `UseOverlayStateReturn` | - | Overlay state from `useOverlayState()` |
| `...rest` | `DialogTriggerProps` | - | [React Aria DialogTrigger attributes](https://react-spectrum.adobe.com/react-aria/DialogTrigger.html) |

### AlertDialog.Trigger

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | Non-interactive element to make pressable |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<E, undefined>` | - | Replaces the rendered `<div>`; `E` defaults to `'div'` |
| `...rest` | `HTMLAttributes` | - | The attributes of the rendered element |

### AlertDialog.Backdrop

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"opaque" \| "blur" \| "transparent"` | `"opaque"` | Backdrop overlay style |
| `isDismissable` | `boolean` | `false` | Close on backdrop interaction |
| `isKeyboardDismissDisabled` | `boolean` | `true` | Disable the Escape key |
| `isOpen` | `boolean` | - | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Initially open, without controlling |
| `onOpenChange` | `(isOpen: boolean) => void` | - | Open state change handler |
| `UNSTABLE_portalContainer` | `HTMLElement` | - | Custom portal container |
| `className` | `string \| ((renderProps) => string)` | - | Additional classes, or a function of the state |
| `...rest` | `ModalOverlayProps` | - | [React Aria ModalOverlay attributes](https://react-spectrum.adobe.com/react-aria/Modal.html) |

### AlertDialog.Container

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `placement` | `"auto" \| "top" \| "center" \| "bottom"` | `"auto"` | Position on screen |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "cover"` | `"md"` | Size variant |
| `className` | `string \| ((renderProps) => string)` | - | Additional classes, or a function of the state |
| `...rest` | `ModalProps` | - | [React Aria Modal attributes](https://react-spectrum.adobe.com/react-aria/Modal.html) |

### AlertDialog.Dialog

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode \| (({close}) => React.ReactNode)` | - | Content, or a function receiving `close` |
| `role` | `"dialog" \| "alertdialog"` | `"alertdialog"` | ARIA role |
| `aria-label` | `string` | - | Accessible name when no `AlertDialog.Heading` is present |
| `aria-labelledby` | `string` | - | ID of the labelling element; set from `AlertDialog.Heading` |
| `aria-describedby` | `string` | - | ID of the describing element |
| `className` | `string` | - | Additional classes |
| `...rest` | `DialogProps` | - | [React Aria Dialog attributes](https://react-spectrum.adobe.com/react-aria/Dialog.html) |

| `...rest` | `ButtonProps` | - | [React Aria Button attributes](https://react-spectrum.adobe.com/react-aria/Button.html); `slot` defaults to `"close"` |

### Render Props

| Prop | Type | Description |
|------|------|-------------|
| `AlertDialog.Backdrop` `className` | `(renderProps: ModalOverlayRenderProps) => string` | Computes classes from `isEntering`, `isExiting` and `state` |
| `AlertDialog.Container` `className` | `(renderProps: ModalRenderProps) => string` | Computes classes from `isEntering`, `isExiting` and `state` |
| `AlertDialog.Dialog` `children` | `(opts: {close: () => void}) => React.ReactNode` | Renders content with a callback that closes the dialog |
