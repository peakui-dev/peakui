### Anatomy

```tsx
import {Button, Modal} from "@peakui/react";

export default () => (
  <Modal>
    <Button>Open modal</Button>
    <Modal.Backdrop>
      <Modal.Container>
        <Modal.Dialog>
          <Modal.CloseTrigger /> {/* Optional: close button */}
          <Modal.Header>
            <Modal.Icon /> {/* Optional: icon */}
            <Modal.Heading />
          </Modal.Header>
          <Modal.Body />
          <Modal.Footer />
        </Modal.Dialog>
      </Modal.Container>
    </Modal.Backdrop>
  </Modal>
);
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The Modal component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/modal.css)):

#### Base & Element Classes [!toc]

- `.modal__trigger` - Trigger element that opens the modal
- `.modal__backdrop` - Overlay backdrop behind the modal
- `.modal__container` - Positioning wrapper with placement support
- `.modal__dialog` - Modal content container
- `.modal__header` - Header section for titles and icons
- `.modal__heading` - Heading element styles
- `.modal__icon` - Optional icon indicator
- `.modal__body` - Main content area
- `.modal__footer` - Footer section for actions
- `.modal__close-trigger` - Close button position styles

#### Backdrop Variant Classes [!toc]

- `.modal__backdrop--opaque` - Opaque dimmed backdrop (default)
- `.modal__backdrop--blur` - Blurred backdrop
- `.modal__backdrop--transparent` - Transparent backdrop

#### Scroll Variant Classes [!toc]

- `.modal__dialog--scroll-inside` - Constrains the dialog for body scrolling
- `.modal__dialog--scroll-outside` - Lets the backdrop scroll the dialog
- `.modal__container--scroll-outside` - Moves scrolling to the backdrop
- `.modal__body--scroll-inside` - Makes only the body scrollable
- `.modal__body--scroll-outside` - Allows full-page scrolling

#### Size Classes [!toc]

- `.modal__dialog--xs`
- `.modal__dialog--sm`
- `.modal__dialog--md`
- `.modal__dialog--lg`
- `.modal__dialog--cover` - Full screen with margins
- `.modal__container--full` - Fullscreen container without padding
- `.modal__dialog--full` - Fullscreen dialog without radius or shadow

### Slots

- `[data-slot="modal-root"]` - The `Modal` root
- `[data-slot="modal-trigger"]` - The `Modal.Trigger` element
- `[data-slot="modal-backdrop"]` - The `Modal.Backdrop` overlay
- `[data-slot="modal-container"]` - The `Modal.Container` positioning wrapper
- `[data-slot="modal-dialog"]` - The `Modal.Dialog` element
- `[data-slot="modal-header"]` - The `Modal.Header` element
- `[data-slot="modal-icon"]` - The `Modal.Icon` element
- `[data-slot="modal-heading"]` - The `Modal.Heading` element
- `[data-slot="modal-body"]` - The `Modal.Body` element
- `[data-slot="modal-footer"]` - The `Modal.Footer` element
- `[data-slot="close-button"]` - The `Modal.CloseTrigger` element; it renders the CloseButton, which keeps its own slot

### Interactive States

The overlay parts carry React Aria animation states:

- **Entering**: `[data-entering="true"]`
- **Exiting**: `[data-exiting="true"]`
- **Placement**: `[data-placement="auto | top | center | bottom"]` on container and dialog

The trigger supports both pseudo-classes and data attributes:

- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[aria-disabled="true"]`
- **Pressed**: `:active` or `[data-pressed="true"]`

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `React.ReactNode` | - | The trigger element followed by the overlay |
| `state` | `UseOverlayStateReturn` | - | Overlay state from `useOverlayState()` |
| `...rest` | `DialogTriggerProps` | - | [React Aria DialogTrigger attributes](https://react-spectrum.adobe.com/react-aria/DialogTrigger.html) |

### useOverlayState

```tsx
import {useOverlayState} from "@peakui/react";

const state = useOverlayState({
  defaultOpen: false,
  onOpenChange: (isOpen) => console.log(isOpen),
});

state.isOpen; // current state
state.open(); // open the overlay
state.close(); // close the overlay
state.toggle(); // toggle the state
state.setOpen(true); // set the state directly
```

### Render Props

| Prop | Type | Description |
|------|------|-------------|
| `Modal.Backdrop` `className` | `(renderProps: ModalOverlayRenderProps) => string` | Computes classes from `isEntering`, `isExiting` and `state` |
| `Modal.Container` `className` | `(renderProps: ModalRenderProps) => string` | Computes classes from `isEntering`, `isExiting` and `state` |
| `Modal.Dialog` `children` | `(opts: {close: () => void}) => React.ReactNode` | Renders content with a callback that closes the modal |
