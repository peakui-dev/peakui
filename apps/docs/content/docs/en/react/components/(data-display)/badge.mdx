## Usage

```tsx
import {Badge} from "@peakui/react";
```

<ComponentPreview name="badge-basic" />

### Anatomy

```tsx
import {Badge} from "@peakui/react";

export default () => (
  <Badge.Anchor>
    {/* the element the badge sits over */}
    <Badge>
      <Badge.Label>5</Badge.Label>
    </Badge>
  </Badge.Anchor>
);
```

A string or a number passed as `children` is wrapped in `Badge.Label` for you.

### Badge or Chip

`Badge` is positioned over a sibling inside `Badge.Anchor`: an avatar with a count, an icon with a
dot. `Chip` is an inline label that takes its own place in the flow.

### Accessibility

A badge has no role and is not announced when it changes, so its meaning belongs in the accessible
name of the element it sits over, as in `aria-label="Inbox, 5 unread"`. The badge renders a plain
`<span>`, so `aria-label` on the badge itself is prohibited and assistive technology ignores it; an
icon inside a badge carries its own name through `role="img"`.

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The Badge component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/badge.css)):

#### Base & Element Classes [!toc]

- `.badge-anchor` - The wrapper the badge is positioned against
- `.badge` - The indicator
- `.badge__label` - The text inside it

#### Size Classes [!toc]

- `.badge--sm`, `.badge--md` (default), `.badge--lg`

#### Color Classes [!toc]

- `.badge--default`, `.badge--accent`, `.badge--success`, `.badge--warning`, `.badge--danger`

#### Variant Classes [!toc]

- `.badge--primary` (default), `.badge--secondary`, `.badge--soft`

#### Placement Classes [!toc]

- `.badge--top-right` (default), `.badge--top-left`, `.badge--bottom-right`, `.badge--bottom-left`

### Slots

- `[data-slot="badge-anchor"]`
- `[data-slot="badge"]`
- `[data-slot="badge-label"]`

### CSS Variables

| Variable | Purpose |
|----------|---------|
| `--badge-bg` | Fill, set by the variant and color classes |
| `--badge-fg` | Text color |
| `--badge-border` | The ring that separates the badge from what it covers; the page background by default |

## API Reference

### Badge

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `color` | `'default' \| 'accent' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Color role |
| `variant` | `'primary' \| 'secondary' \| 'soft'` | `'primary'` | Fill style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size |
| `placement` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | Corner of the anchor |
| `children` | `ReactNode` | - | A string or number is wrapped in `Badge.Label`; omit it for a dot |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<E, undefined>` | - | Replaces the rendered element; `E` defaults to `'span'` |
| `...rest` | | | Every `<span>` attribute is accepted |

### Badge.Anchor

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | The element the badge sits over, and the badge |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<E, undefined>` | - | Replaces the rendered element; `E` defaults to `'span'` |
| `...rest` | | | Every `<span>` attribute is accepted |

### Badge.Label

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | - | The text |
| `className` | `string` | - | Additional classes |
| `render` | `DOMRenderFunction<E, undefined>` | - | Replaces the rendered element; `E` defaults to `'span'` |
| `...rest` | | | Every `<span>` attribute is accepted |
