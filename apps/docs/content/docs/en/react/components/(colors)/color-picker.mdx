### Anatomy

The ColorPicker is a container: it owns the value and the popover, and any React Aria editor composed inside reads and writes that value through the picker's state.

```tsx
import {ColorSlider, ColorThumb, SliderTrack} from "react-aria-components/ColorSlider";
import {ColorPicker, ColorSwatch, Label} from "@peakui/react";

export default () => (
  <ColorPicker defaultValue="#0485F7">
    <ColorPicker.Trigger>
      <ColorSwatch />
      <Label>Pick a color</Label>
    </ColorPicker.Trigger>
    <ColorPicker.Popover>
      <ColorSlider channel="hue" colorSpace="hsb">
        <SliderTrack>
          <ColorThumb />
        </SliderTrack>
      </ColorSlider>
    </ColorPicker.Popover>
  </ColorPicker>
);
```

The component supports both CSS pseudo-classes and data attributes:

- **Focus**: `:focus-visible` or `[data-focus-visible="true"]` on trigger
- **Disabled**: `:disabled`, `[data-disabled="true"]` or `[aria-disabled="true"]` on trigger

## API Reference

### ColorPicker

Inherits from [React Aria ColorPicker](https://react-spectrum.adobe.com/react-aria/ColorPicker.html).

| Prop           | Type                                    | Default | Description                                    |
| -------------- | --------------------------------------- | ------- | ---------------------------------------------- |
| `value`        | `string \| Color`                       | -       | The current color value (controlled)           |
| `defaultValue` | `string \| Color`                       | -       | The default color value (uncontrolled)         |
| `onChange`     | `(color: Color) => void`                | -       | Handler called when the color changes          |
| `children`     | `ReactNode`                             | -       | Content of the color picker (Trigger, Popover) |
| `className`    | `string`                                | -       | Additional class name for the wrapper element  |
| `...rest`      |                                         |         | Every React Aria `ColorPicker` attribute is accepted, including `isDisabled` and `aria-label` |

### ColorPicker.Trigger

| Prop        | Type                                                    | Default | Description                                    |
| ----------- | ------------------------------------------------------- | ------- | ---------------------------------------------- |
| `className` | `string`                                                | -       | Additional classes                             |
| `children`  | `ReactNode \| ((values: ButtonRenderProps) => ReactNode)` | -     | Trigger content, or a function of the render props |
| `...rest`   |                                                         |         | Every React Aria `Button` attribute is accepted |

### ColorPicker.Popover

| Prop        | Type                                                                                                                                                                                                               | Default         | Description                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- | ------------------------------------------------ |
| `placement` | `"bottom" \| "bottom left" \| "bottom right" \| "bottom start" \| "bottom end" \| "top" \| "top left" \| "top right" \| "top start" \| "top end" \| "left" \| "left top" \| "left bottom" \| "start" \| "start top" \| "start bottom" \| "right" \| "right top" \| "right bottom" \| "end" \| "end top" \| "end bottom"` | `"bottom left"` | Placement of the popover relative to the trigger |
| `className` | `string`                                                                                                                                                                                                           | -               | Additional classes                               |
| `children`  | `ReactNode`                                                                                                                                                                                                        | -               | Popover content                                  |
| `...rest`   |                                                                                                                                                                                                                    |                 | Every React Aria `Popover` attribute is accepted |

### Related Types

#### Color

Represents a color value. See [React Aria Color](https://react-spectrum.adobe.com/react-aria/ColorPicker.html#color) for the full API.

| Method                     | Description                                                            |
| -------------------------- | ---------------------------------------------------------------------- |
| `toString(format)`         | Converts the color to a string in the given format (hex, rgb, hsl, hsb, css) |
| `toFormat(format)`         | Converts the color to the given format and returns a new Color         |
| `getChannelValue(channel)` | Returns the numeric value for a given channel                          |
| `withChannelValue(channel, value)` | Sets the numeric value for a channel and returns a new Color   |

#### parseColor

```tsx
import {parseColor} from "react-aria-components";

// Parse from string
const color = parseColor("#ff0000");
const hslColor = parseColor("hsl(0, 100%, 50%)");
```
