## Usage

```tsx
import {TimeField, Label} from "@peakui/react";
```

<ComponentPreview name="time-field-basic" />

### Anatomy

```tsx
import {TimeField, Description, FieldError, Label} from "@peakui/react";

export default () => (
  <TimeField>
    <Label />
    <TimeField.Group>
      <TimeField.Prefix />
      <TimeField.InputContainer>
        <TimeField.Input>{(segment) => <TimeField.Segment segment={segment} />}</TimeField.Input>
      </TimeField.InputContainer>
      <TimeField.Suffix />
    </TimeField.Group>
    <Description />
    <FieldError />
  </TimeField>
);
```

## Styling Reference

PeakUI follows the [BEM](https://getbem.com/) methodology, so variants and states are plain class names you can target.

### CSS Classes

The TimeField component uses these CSS classes ([view source styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/time-field.css) and [group styles](https://github.com/peakui-dev/peakui/blob/main/packages/styles/components/date-input-group.css)):

#### Field Classes [!toc]

- `.time-field` - Column of label, group and messages
- `.time-field--full-width` - Fills the container width

#### Group Classes [!toc]

- `.date-input-group` - Shell with fill, border and focus ring
- `.date-input-group__input` - Borderless, transparent segmented input
- `.date-input-group__input-container` - Horizontal scroll area around the input
- `.date-input-group__segment` - One editable part of the date
- `.date-input-group__prefix` - Slot before the input
- `.date-input-group__suffix` - Slot after the input

#### Variant Classes [!toc]

- `.date-input-group--primary` - Field fill with shadow (default)
- `.date-input-group--secondary` - Neutral fill without shadow

#### Modifier Classes [!toc]

- `.date-input-group--full-width` - Fills the container width

### Interactive States

- **Hover**: `:hover` or `[data-hovered]` on `.date-input-group`
- **Focus**: `:focus-within` or `[data-focus-within]` on `.date-input-group`; `:focus` or `[data-focused]` on `.date-input-group__segment`
- **Placeholder**: `[data-placeholder]` on `.date-input-group__segment`
- **Invalid**: `[data-invalid]` or `[aria-invalid="true"]` on `.date-input-group`, `[data-invalid]` on the segment, and the field hides its description
- **Disabled**: `[data-disabled]` or `[aria-disabled="true"]` on `.date-input-group`

## API Reference

### TimeField

| Prop                    | Type                                                    | Default | Description                                                    |
| ----------------------- | ------------------------------------------------------- | ------- | -------------------------------------------------------------- |
| `fullWidth`             | `boolean`                                               | `false` | Makes the field fill its container                             |
| `value`                 | `TimeValue \| null`                                     | -       | The current time (controlled)                                  |
| `defaultValue`          | `TimeValue \| null`                                     | -       | The initial time (uncontrolled)                                |
| `onChange`              | `(value: MappedTimeValue<T> \| null) => void`           | -       | Called when the time changes                                   |
| `minValue`              | `TimeValue \| null`                                     | -       | Earliest valid time                                            |
| `maxValue`              | `TimeValue \| null`                                     | -       | Latest valid time                                              |
| `placeholderValue`      | `TimeValue \| null`                                     | -       | Time the empty segments start from when stepped                |
| `granularity`           | `"hour" \| "minute" \| "second"`                        | `"minute"` | Smallest unit shown                                         |
| `hourCycle`             | `12 \| 24`                                              | -       | Clock used for hours; follows the locale by default            |
| `hideTimeZone`          | `boolean`                                               | `false` | Hides the time zone of a zoned value                           |
| `shouldForceLeadingZeros` | `boolean`                                             | -       | Pads every segment to its full width                           |
| `isDisabled`            | `boolean`                                               | `false` | Disables the field                                             |
| `isReadOnly`            | `boolean`                                               | `false` | Keeps the value but blocks editing                             |
| `isRequired`            | `boolean`                                               | `false` | Requires a value; sets `data-required`                         |
| `isInvalid`             | `boolean`                                               | -       | Marks the field invalid                                        |
| `name`                  | `string`                                                | -       | Name of the hidden input submitted with a form                 |
| `className`             | `string \| ((values: TimeFieldRenderProps) => string)`  | -       | Additional classes, or a function of the render props          |
| `...rest`               |                                                         |         | Every React Aria `TimeField` prop                              |

### TimeField.Group

| Prop        | Type                                               | Default     | Description                                           |
| ----------- | -------------------------------------------------- | ----------- | ----------------------------------------------------- |
| `variant`   | `"primary" \| "secondary"`                         | `"primary"` | Visual style of the group                             |
| `fullWidth` | `boolean`                                          | `false`     | Makes the group fill its container                    |
| `className` | `string \| ((values: GroupRenderProps) => string)` | -           | Additional classes, or a function of the render props |
| `...rest`   |                                                    |             | Every React Aria `Group` prop                         |

### TimeField.Input

| Prop        | Type                                                   | Default | Description                                                   |
| ----------- | ------------------------------------------------------ | ------- | ------------------------------------------------------------- |
| `children`  | `(segment: DateSegment) => ReactElement`               | -       | Renders one segment; pass it to `TimeField.Segment`           |
| `className` | `string \| ((values: DateInputRenderProps) => string)` | -       | Additional classes, or a function of the render props         |
| `...rest`   |                                                        |         | Every React Aria `DateInput` prop                             |

### TimeField.InputContainer

| Prop        | Type                              | Default | Description                                            |
| ----------- | --------------------------------- | ------- | ------------------------------------------------------ |
| `render`    | `DOMRenderFunction<E, undefined>` | -       | Replaces the rendered element; `E` defaults to `"div"` |
| `className` | `string`                          | -       | Additional classes                                     |
| `...rest`   |                                   |         | Every attribute of the rendered element                |

### TimeField.Segment

| Prop        | Type          | Default | Description                                  |
| ----------- | ------------- | ------- | -------------------------------------------- |
| `segment`   | `DateSegment` | -       | The segment passed by `TimeField.Input`      |
| `className` | `string`      | -       | Additional classes                           |
| `...rest`   |               |         | Every React Aria `DateSegment` prop          |

| `className` | `string`                          | -       | Additional classes                                     |
| `...rest`   |                                   |         | Every attribute of the rendered element                |

### TimeField.Suffix

| Prop        | Type                              | Default | Description                                            |
| ----------- | --------------------------------- | ------- | ------------------------------------------------------ |

### Render Props

`className` on `TimeField` receives these values:

| Prop         | Type      | Description                     |
| ------------ | --------- | ------------------------------- |
| `isInvalid`  | `boolean` | Whether the field is invalid    |
| `isDisabled` | `boolean` | Whether the field is disabled   |
| `isReadOnly` | `boolean` | Whether the field is read only  |
