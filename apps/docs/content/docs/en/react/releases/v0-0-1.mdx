**October 2026**

First public release. `@peakui/react` and `@peakui/styles` publish in lockstep from the npm
organization [`peakui`](https://www.npmjs.com/org/peakui).

## Installing

```bash
npm install @peakui/react @peakui/styles
```

## What shipped

- **Components** built on React Aria Components: buttons and toggles, forms and text inputs,
  pickers (select, combo box, autocomplete, date and range pickers, calendars), colour
  components, overlays (modal, drawer, popover, tooltip, toast, alert dialog), navigation,
  feedback (alert, progress, meter, skeleton, spinner), data display and layout.
- **`@peakui/styles`** — the design-token layer, base styles, the default theme and the
  component styles every `@peakui/react` component renders against.
- **Docs** — a page for every component at [Components](/docs/react/components).
