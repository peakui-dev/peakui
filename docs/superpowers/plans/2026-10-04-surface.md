# `Surface` Implementation Plan (roadmap entry 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the reference's `surface` component 1:1 into `@peakui/react` with styles, stories, tests, docs and the `apps/docs` sixth-stage migration.

**Architecture:** A leaf layout component with a context — `SurfaceRoot<E>` over `dom.div`, `SurfaceContext` carrying `{variant}`, BEM `.surface--*` from `tv()`, Tailwind in `@peakui/styles` CSS. No RAC primitive.

**Tech Stack:** React 19, `tailwind-variants`, Tailwind v4 CSS, vitest + `@testing-library/react`.

**Spec:** `docs/superpowers/specs/2026-10-04-surface-design.md` (approved by human, 2026-10-04). The spec holds the exact API, class names and migration targets; this plan sequences the work.

- Test names in Russian; stories beside the component titled `Components/Surface`; docs page `(layout)/surface.mdx` + demos per `peakui-docs`.
