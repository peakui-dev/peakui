## Review Focus

1. **Keyboard selection.** Enter/Space/ArrowDown opens; arrows move; Enter selects and closes;
   typeahead jumps to a typed prefix. The trigger keeps `aria-haspopup="listbox"` and reflects
   `aria-expanded`.
2. **The clear path.** `Select.ClearButton` clears on a primary-button click and reports `onClear`;
   Backspace/Delete on the trigger clears **only** when a `ClearButton` is composed and the
   selection is non-empty — a plain `Select` stays non-clearable. This behaviour is the reference's
   own (see `select.tsx`'s comments); port it with its comments.
3. **Controlled selection.** `selectedKey` + `onChange` follow rerenders; `isOpen`/`onOpenChange`
   control the popover.
4. **Multiple selection.** `selectionMode="multiple"` collects keys and `SelectValue` renders them.
5. **Forced colours.** The trigger's boundary and the popover's surface must stay distinguishable
   under `forced-colors`; the popover is a `Surface` consumer.

**Interfaces:**
- Produces, consumed by `peakui-pro`'s `CellSelect` and later by `InlineSelect`:

```ts
export const Select = Object.assign(SelectRoot, {
  Root: SelectRoot, Trigger: SelectTrigger, Value: SelectValue,
  Indicator: SelectIndicator, ClearButton: SelectClearButton, Popover: SelectPopover,
});
// SelectRootProps<T, M> = RAC Select<T, M> props + fullWidth + variant + onClear + items
// SelectTriggerProps = RAC Button props
// SelectValueProps = RAC SelectValue props
// SelectIndicatorProps = polymorphic svg part; a child element is cloned with the classes,
//   data-slot="select-indicator" and data-open; without a child, the default chevron renders
// SelectPopoverProps = RAC Popover props, placement default "bottom"
```

  `peakui-pro` relies on: the six parts; `data-slot` values `select-trigger`, `select-value`,
  `select-indicator`, `select-popover`; the indicator's clone + `data-open` behaviour; the
  popover's `placement` prop.

- [ ] **Step 2: Write the failing tests** in `select.test.tsx`, replacing the scaffold's
  placeholders. The house imports and the overlay-timers wrapper, as the dropdown suite does:

```tsx
import {act, render, screen, setupUser} from "@peakui/testing/helpers";

/* Overlay state updates run through the timers wrapper, as the dropdown suite records. */
const runAllTimers = () => act(() => vi.runAllTimers());

const FRUITS = [
  {id: "apple", label: "Apple"},
  {id: "banana", label: "Banana"},
];

function FruitSelect(props = {}) {
  return (
    <Select aria-label="Fruit" items={FRUITS} {...props}>
      <Select.Trigger>
        <Select.Value />
        <Select.Indicator />
      </Select.Trigger>
      <Select.Popover>
        <ListBox>
          {(item) => <ListBox.Item id={item.id}>{item.label}</ListBox.Item>}
        </ListBox>
      </Select.Popover>
    </Select>
  );
}

it("opens on press and selects an option", async () => {
  const user = setupUser();
  render(<FruitSelect />);

  await user.click(screen.getByRole("combobox", {name: "Fruit"}));

  expect(screen.getByRole("listbox")).toBeVisible();

  await user.click(screen.getByRole("option", {name: "Banana"}));

  expect(screen.getByRole("combobox")).toHaveTextContent("Banana");
  expect(screen.queryByRole("listbox")).not.toBeInTheDocument();
});

it("selects by keyboard and reports to onChange", async () => {
  const user = setupUser();
  const onSelectionChange = vi.fn();
  render(<FruitSelect onSelectionChange={onSelectionChange} />);

  const trigger = screen.getByRole("combobox", {name: "Fruit"});
  trigger.focus();
  await user.keyboard("{Enter}");
  await user.keyboard("{ArrowDown}");
  await user.keyboard("{Enter}");

  expect(onSelectionChange).toHaveBeenCalledWith("apple");
});

it("clears through the clear button and reports onClear", async () => {
  const user = setupUser();
  const onClear = vi.fn();
  render(
    <FruitSelect defaultSelectedKey="apple" onClear={onClear}>
      <Select.Trigger>
        <Select.Value />
        <Select.Indicator />
        <Select.ClearButton />
      </Select.Trigger>
      <Select.Popover>{/* list as above */}</Select.Popover>
    </Select>,
  );

  await user.click(screen.getByRole("combobox", {name: "Fruit"}));
  expect(screen.getByRole("combobox")).toHaveTextContent("Apple");

  await user.click(screen.getByRole("combobox").querySelector('[data-slot="select-clear-button"]')!);

  expect(screen.getByRole("combobox")).not.toHaveTextContent("Apple");
  expect(onClear).toHaveBeenCalledOnce();
});

it("Backspace on the trigger clears only when a clear button is composed", async () => {
  const user = setupUser();
  const {rerender} = render(<FruitSelect defaultSelectedKey="apple" />);

  const trigger = screen.getByRole("combobox", {name: "Fruit"});
  trigger.focus();
  await user.keyboard("{Backspace}");
  expect(trigger).toHaveTextContent("Apple");

  rerender(
    <FruitSelect defaultSelectedKey="apple">
      <Select.Trigger>
        <Select.Value />
        <Select.Indicator />
        <Select.ClearButton />
      </Select.Trigger>
      <Select.Popover>{/* list as above */}</Select.Popover>
    </FruitSelect>,
  );

  trigger.focus();
  await user.keyboard("{Backspace}");
  expect(screen.getByRole("combobox")).not.toHaveTextContent("Apple");
});

it("marks the indicator with the open state", async () => {
  const user = setupUser();
  render(<FruitSelect />);

  const indicator = screen.getByRole("combobox").querySelector('[data-slot="select-default-indicator"]')!;

  expect(indicator).toHaveAttribute("data-open", "false");

  await user.click(screen.getByRole("combobox", {name: "Fruit"}));

  expect(indicator).toHaveAttribute("data-open", "true");
});

it("collects keys in multiple mode", async () => {
  const user = setupUser();
  render(<FruitSelect selectionMode="multiple" />);

  await user.click(screen.getByRole("combobox", {name: "Fruit"}));
  await user.click(screen.getByRole("option", {name: "Apple"}));
  await user.click(screen.getByRole("option", {name: "Banana"}));

  expect(screen.getByRole("combobox")).toHaveTextContent("Apple");
  expect(screen.getByRole("combobox")).toHaveTextContent("Banana");
});

it("carries variant and fullWidth as classes", () => {
  render(<FruitSelect fullWidth variant="flat" />);

  expect(screen.getByRole("combobox").closest('[data-slot="select"]')!.className).toContain("select--flat");
  expect(screen.getByRole("combobox").closest('[data-slot="select"]')!.className).toContain("select--full-width");
});
```

  Variant names above are the reference's — take the exact set and class names from
  `@heroui/styles`' `selectVariants`, not from this example. Keep the scaffold's
