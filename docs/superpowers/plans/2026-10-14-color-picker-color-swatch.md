## Review Focus

1. **State without an editor.** This order ships no editing part (`ColorArea`, `ColorSlider`,
   `ColorField` and `ColorSwatchPicker` are wave 3.5), so the picker is a container: its value
   flows to composed children through RAC's state, and `onChange` fires when a bare RAC editor is
   composed by a consumer. The tests compose one on purpose.
2. **The swatch's colour channel.** `ColorSwatch` publishes the colour as the
   `--color-swatch-current` custom property through a `style` render prop — a consumer's `style`
   must survive beside it, including a functional `style`.
3. **Controlled and uncontrolled value.** `defaultValue` seeds the state; `value` rules it on
   rerender; both reach a composed `ColorSwatch`.
4. **The popover is a Surface consumer**, opening from a RAC `Button` trigger, with
   `forced-colors` keeping the surface distinguishable.

```tsx
import {act, render, screen, setupUser} from "@peakui/testing/helpers";
import {parseColor, ColorSlider} from "react-aria-components";

/* Overlay state updates run through the timers wrapper, as the dropdown suite records. */
const runAllTimers = () => act(() => vi.runAllTimers());

function Picker(props = {}) {
  return (
    <ColorPicker defaultValue={parseColor("#ff5733")} {...props}>
      <ColorPicker.Trigger aria-label="Accent colour">
        <ColorSwatch aria-label="Current colour" data-testid="swatch" />
      </ColorPicker.Trigger>
      <ColorPicker.Popover>
        <ColorSlider channel="red" />
      </ColorPicker.Popover>
    </ColorPicker>
  );
}

it("renders its trigger and opens the popover on press", async () => {
  const user = setupUser();
  render(<Picker />);

  await user.click(screen.getByRole("button", {name: "Accent colour"}));
  runAllTimers();

  expect(screen.getByRole("dialog")).toBeVisible();
});

it("seeds the state from defaultValue for composed children", () => {
  render(<Picker />);

  expect(screen.getByTestId("swatch").style.getPropertyValue("--color-swatch-current")).toBe(
    "rgb(255, 87, 51)",
  );
});

it("follows a controlled value on rerender", () => {
  const {rerender} = render(<Picker value={parseColor("#ff5733")} />);

  rerender(<Picker value={parseColor("#00ff00")} />);

  expect(screen.getByTestId("swatch").style.getPropertyValue("--color-swatch-current")).toBe(
    "rgb(0, 255, 0)",
  );
});

it("reports edits to onChange from a composed editor", async () => {
  const user = setupUser();
  const onChange = vi.fn();
  render(<Picker onChange={onChange} />);

  await user.click(screen.getByRole("button", {name: "Accent colour"}));
  runAllTimers();

  const slider = screen.getByRole("slider");
  slider.focus();
  await user.keyboard("{ArrowRight}");

  expect(onChange).toHaveBeenCalled();
});
```

  The composed `ColorSlider` is a test device, not a dependency: this order ships no editor part
