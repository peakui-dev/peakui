## Review Focus

1. **A bar with no visible label.** A consumer renders `<ProgressBar aria-label="Loading"
   value={40}>` with only a track — the case `peakui-pro` uses. It must expose
   `role="progressbar"` with that name and `aria-valuenow="40"`.
2. **Indeterminate.** `isIndeterminate` must leave `aria-valuenow` off and give the fill no
   inline width; the animation must stop under `prefers-reduced-motion`.
3. **Out-of-range and custom ranges.** `value` above `maxValue` clamps; `minValue` and
   `maxValue` other than 0–100 produce the right percentage in the fill's width.
4. **Forced colours.** Track and fill are distinguished by background alone; in `forced-colors`
   both would vanish. The fill must stay visible against the track.
5. **Right-to-left.** The fill grows from the inline start.

  Root: ProgressBarRoot,
  Output: ProgressBarOutput,
  Track: ProgressBarTrack,
  Fill: ProgressBarFill,

- [ ] **Step 2: Write the failing tests** in `progress-bar.test.tsx`, replacing the scaffold's

```tsx
it("exposes the value to assistive technology under the given name", () => {
  render(
    <ProgressBar aria-label="Loading" value={40}>
      <ProgressBar.Track>
        <ProgressBar.Fill />
      </ProgressBar.Track>
    </ProgressBar>,
  );

  const bar = screen.getByRole("progressbar", {name: "Loading"});

  expect(bar).toHaveAttribute("aria-valuenow", "40");
  expect(bar).toHaveAttribute("data-slot", "progress-bar");
});

it("sizes the fill from the value within a custom range", () => {
  render(
    <ProgressBar aria-label="Steps" maxValue={8} minValue={0} value={2}>
      <ProgressBar.Track>
        <ProgressBar.Fill data-testid="fill" />
      </ProgressBar.Track>
    </ProgressBar>,
  );

  expect(screen.getByTestId("fill").style.width).toBe("25%");
});

it("clamps a value above the maximum", () => {
  render(
    <ProgressBar aria-label="Over" value={140}>
      <ProgressBar.Track>
        <ProgressBar.Fill data-testid="fill" />
      </ProgressBar.Track>
    </ProgressBar>,
  );

  expect(screen.getByTestId("fill").style.width).toBe("100%");
});

it("leaves the value and the fill width off when indeterminate", () => {
  render(
    <ProgressBar aria-label="Working" isIndeterminate>
      <ProgressBar.Track>
        <ProgressBar.Fill data-testid="fill" />
      </ProgressBar.Track>
    </ProgressBar>,
  );

  expect(screen.getByRole("progressbar")).not.toHaveAttribute("aria-valuenow");
  expect(screen.getByTestId("fill").style.width).toBe("");
});

it("shows the formatted value in the output, or the children given to it", () => {
  const {rerender} = render(
    <ProgressBar aria-label="Upload" value={40}>
      <ProgressBar.Output data-testid="out" />
    </ProgressBar>,
  );

  expect(screen.getByTestId("out")).toHaveTextContent("40%");
  rerender(
    <ProgressBar aria-label="Upload" value={40}>
      <ProgressBar.Output data-testid="out">2 of 5</ProgressBar.Output>
    </ProgressBar>,
  );
  expect(screen.getByTestId("out")).toHaveTextContent("2 of 5");
});

it("carries the colour and size variants as classes", () => {
  render(<ProgressBar aria-label="Disk" color="danger" size="sm" value={90} />);

  const bar = screen.getByRole("progressbar");

  expect(bar.className).toContain("progress-bar--danger");
  expect(bar.className).toContain("progress-bar--sm");
});
```
